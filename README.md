# DWG 导入器（Import DWG）

在嘉立创EDA专业版（EasyEDA Pro）里，直接把 **DWG** 图纸导入到 **PCB / 原理图 / 封装** 编辑器中。

机械工程师给的板框、外形图、结构参考图，不用再手抄坐标，选好文件、配好图层对应关系，一键就能落到画布上。

---

## 这个扩展能做什么

- **一键导入 DWG**：在 PCB、原理图、封装三种编辑器里都能用。
- **图层映射**：DWG 里的每个图层，可以分别指定导入到哪个 PCB 层（比如板框、丝印、机械层）。选不定时，扩展会按图层颜色和图层名自动给出建议。
- **自动展开图块（BLOCK）**：DWG 里用图块拼出来的图形（比如标准件、反复出现的标记），导入时会展开成实际图形，不会漏。
- **可挑选导入内容**：只想导入线条？可以在选项里关掉文字、样条曲线等类型。
- **常用设置记着**：上次用的线宽、单位会记住，下次不用重设。
- **中英双语**：界面跟随嘉立创EDA的语言设置。

## 怎么用

### 第一步：打开菜单

先打开一个 **PCB**、**原理图** 或 **封装** 文档，然后在顶部菜单里找到：

```
DWG 导入器  →  导入 DWG…
```

> 只有在上面这三种编辑器里才会出现这个菜单。在主页、工程列表、符号编辑器等界面是看不到的。

### 第二步：选择 DWG 文件

弹出的窗口里，把 `.dwg` 文件拖进去，或者点「选择文件…」挑一个。

选好后会自动开始解析，状态栏会显示解析进度。解析完成时能看到有多少个图形、多少个图层。

### 第三步：设置图层对应关系

窗口中间是**图层映射表**，左边是 DWG 里的图层，右边下拉选择要放到 PCB 的哪一层。

表头上有几个省事的按钮：

| 按钮 | 作用 |
|---|---|
| **全选 / 全不选** | 快速勾选或取消所有图层 |
| **按颜色匹配** | 按图层颜色，自动找颜色最接近的 PCB 层 |
| **按名字建议** | 按图层名字猜，例如 `BOARD_OUTLINE` → 板框层，`DIM*` → 机械层 |
| **重置** | 清空所有映射，重新来 |

不想导入某个图层，就把它右边的下拉设成 **「不导入」**，或者取消前面的勾。

> 自动建议只是帮你省事，**不一定完全准确**。导入前建议扫一眼，按自己的习惯调整。

### 第四步：调整选项（可选）

展开「选项」区域可以：

- **实体类型**：勾选要导入哪些类型。默认全选。如果只想导入线条轮廓，可以取消掉 TEXT、MTEXT、SPLINE。
- **默认线宽**：导入图形的线宽，默认 8 mil，有 1 / 2 / 4 / 6 / 8 / 10 / 20 mil 可选。
- **单位**：默认「自动」，即按 DWG 文件本身记录的单位来；如果发现导入后尺寸不对，可以手动改成 mm 或 inch。
- **跳过空图层**：默认开启。没内容的图层不处理，导入更快。

### 第五步：确认并导入

窗口底部会显示「导入（N 个图元）」。点它开始导入，完成后会自动缩放到刚导入的图形，方便查看。

> 导入**不会**自动保存文档，方便你先检查效果。确认没问题再自己保存。

## 支持哪些图形

| DWG 图形 | 能否导入 | 说明 |
|---|---|---|
| 直线（LINE） | ✅ | |
| 无限长构造线（XLINE / RAY） | ✅ | 按图纸实际范围裁剪后作为直线导入 |
| 多段线（LWPOLYLINE / POLYLINE） | ✅ | 闭合多段线作为轮廓区域导入；顶点凸度（圆弧段）会展开成折线 |
| 圆（CIRCLE）、圆弧（ARC）、椭圆（ELLIPSE） | ✅ | 会转换成细密的折线 |
| 单行文字（TEXT） | ✅ | |
| 多行文字（MTEXT） | ✅ | 按硬换行与参照矩形宽度拆成多行，逐行下排 |
| 样条曲线（SPLINE，含贝塞尔） | ✅ | 先按定义求值再采样成折线，保证外形平滑 |
| 图块引用（INSERT） | ✅ | 自动展开成实际图形（嵌套、缩放、旋转、镜像） |
| 标注（DIMENSION） | ✅ | 经其匿名块导入（CAD 里标注就是渲染该块） |
| 表格（ACAD_TABLE） | ✅ | 经表格匿名块导入，含表格线框与单元格文字 |
| 遮罩（WIPEOUT） | ✅ | EDA 没有遮罩图元，导入为闭合轮廓以保留可见边界 |
| 点（POINT）、填充（HATCH）、多线（MLINE）、引线（MULTILEADER）、公差（TOLERANCE）、属性（ATTDEF / ATTRIB） | ❌ | 不导入，但在解析警告中按类型列出数量 |
| 面域（REGION）、三维实体（3DSOLID / BODY） | ❌ | 解析库只提供 ACIS 数据，没有可用的二维几何 |

**外部参照（XREF）**：如果 DWG 引用了其它外部文件，因为这些内容不在当前文件里，扩展会跳过它并以提示条告知（详情见日志），其余图形照常导入。

## 常见问题

**菜单找不到？**
请确认当前打开的是 PCB、原理图或封装文档。其它界面（主页、工程树、符号编辑器、面板等）不会显示这个菜单。

**导入后尺寸差 10 倍或 25 倍？**
多半是单位识别问题。打开「选项」把「单位」从「自动」改成 **mm** 或 **inch** 再导一次。DWG 文件中记录的单位有时不准确，尤其从英寸制国家传来的图纸。

**为什么不用 DXF？**
嘉立创EDA 专业版**原生支持导入 DXF**，直接用软件自带的导入功能即可，不需要经过本扩展。本扩展专门解决软件不支持的 DWG 格式。

**提示「无法加载 DWG 解析引擎」？**
说明扩展包里的解析模块没加载成功。可以在扩展管理里重新安装一次；若一直失败，请反馈给我们。

**提示「DWG 版本不受支持」？**
解析引擎对很新的 DWG 版本（如 AutoCAD 2018 及以上）支持有限。可以在 AutoCAD 或其它 CAD 软件里「另存为」较早的版本（如 2013 或 2010），再重新导入。

**文件太大导不进来？**
单次导入有上限：文件不超过 **50 MB**，图形数量不超过 **10 万个**。图形特别多时，可以按图层拆分，分几次导入。

**导入的图形跑到很远的地方了？**
确认「单位」设置正确；另外注意导入的坐标是 DWG 原始坐标，可能与当前画布原点有偏移。导入完成后会自动缩放到导入内容，如果没看到图形，可以按一下「适应全部」。

**导入后文字字体变了？**
DWG 里的字体在转换中用嘉立创EDA的默认字体显示，字形可能与原图略有差异，属正常现象。

在嘉立创EDA专业版的**扩展广场**中搜索「DWG 导入器」安装即可。
